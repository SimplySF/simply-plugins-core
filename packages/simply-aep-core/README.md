# @simplysf/simply-aep-core

[![NPM](https://img.shields.io/npm/v/@simplysf/simply-aep-core?label=@simplysf/simply-aep-core)](https://npmjs.com/@simplysf/simply-aep-core) [![Downloads/week](https://img.shields.io/npm/dw/@simplysf/simply-aep-core.svg)](https://npmjs.com/@simplysf/simply-aep-core) [![License: Apache-2.0](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://raw.githubusercontent.com/SimplySF/simply-plugins-core/main/LICENSE.txt)

Apex Enterprise Patterns ([fflib](https://github.com/apex-enterprise-patterns/fflib-apex-common), [force-di](https://github.com/apex-enterprise-patterns/force-di), [AT4DX](https://github.com/apex-enterprise-patterns/at4dx)) binding scan and resolution logic. This is not a Salesforce CLI plugin — it's the library layer behind [`@simplysf/simply-aep`](https://github.com/SimplySF/simply-plugins/tree/main/packages/simply-aep)'s `sf simply aep at4dx ...` commands, published separately so it can be imported directly by anything that wants the same data (an editor extension, a CI check, a script) without pulling in the CLI framework.

Unlike the other internal libraries in this monorepo (`@simplysf/simply-core`, `@simplysf/simply-plugin-kit`, `@simplysf/simply-report`), this package is meant to be depended on by projects outside this repo, not only by other `simply-*` packages.

## Install

```bash
npm install @simplysf/simply-aep-core
```

Requires Node.js `>=22` and either `"type": "module"` or a dynamic `import()` — this package ships ESM only.

## API

Everything below is exported from the package root. Removing or renaming an export is a breaking change; see [`src/index.ts`](src/index.ts).

### AT4DX Application Factory bindings

The four `ApplicationFactory_{Service,Selector,Domain,UnitOfWork}Binding__mdt` Custom Metadata Types — "which class implements interface/SObject X" — resolved down to which record wins per key. See [`simply-aep`'s design doc](https://github.com/SimplySF/simply-plugins-core/blob/main/docs/design/0007-at4dx-binding-list.md) for the resolution rules this ports from AT4DX's own `di_Module` subclasses.

| Export                                                                                                                                                                                                                     | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `scanOrgBindings(connection, types)`                                                                                                                                                                                       | Queries a live org (plain REST, no Tooling API) for the requested binding types.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `scanLocalBindings(sourceDirs, types)`                                                                                                                                                                                     | Scans local Salesforce DX source directories for the same data, parsing `CustomMetadata` component XML directly.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `scanOrgApexTriggers(connection)`, `scanLocalApexTriggers(sourceDirs)`                                                                                                                                                     | Scan a target org (Tooling API) or local DX source for Apex triggers, parsing each trigger's target SObject and any `fflib_SObjectDomain.triggerHandler(...)` calls it makes — the input `validateBindings`'s `missing-domain-trigger` rule needs. See [design doc 0036](https://github.com/SimplySF/simply-plugins-core/blob/main/docs/design/0036-at4dx-domain-binding-trigger-validate.md).                                                                                                                                                                                                                                                                                                                                                                     |
| `resolveBindings(records)`                                                                                                                                                                                                 | Pure function: applies AT4DX's per-type resolution rules (priority ordering, Domain ambiguity, UnitOfWork ordering).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `validateBindings(records, diagnostics, triggers?)`                                                                                                                                                                        | Pure function: checks a scan's records/diagnostics for a missing/ambiguous/ineligible SObject reference, a duplicate `To__c`, a duplicate Domain SObject, and duplicate `DeveloperName`s (Service/Selector/Domain only — `UnitOfWork` is never validated). Passing `triggers` (from `scanLocalApexTriggers`/`scanOrgApexTriggers`) additionally checks every Domain binding for a wiring trigger (`missing-domain-trigger`) — omitted, that one check is skipped and nothing else changes. See [design doc 0015](https://github.com/SimplySF/simply-plugins-core/blob/main/docs/design/0015-at4dx-binding-validate-create-set.md) and [0036](https://github.com/SimplySF/simply-plugins-core/blob/main/docs/design/0036-at4dx-domain-binding-trigger-validate.md). |
| `createBinding(input, target)`, `updateBinding(input, target)`                                                                                                                                                             | Create or update a Service/Selector/Domain binding record — writes local DX source, deploys to a connected org, or both — validating the result first and refusing to write a wiring problem unless `force` is passed. See [design doc 0015](https://github.com/SimplySF/simply-plugins-core/blob/main/docs/design/0015-at4dx-binding-validate-create-set.md).                                                                                                                                                                                                                                                                                                                                                                                                     |
| `buildBindingXml(record, meta)`                                                                                                                                                                                            | Pure function: serializes a record to the full `.md-meta.xml` text `createBinding`/`updateBinding` write.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `bindingTypeForLocalObjectName(name)`                                                                                                                                                                                      | Maps a local `CustomMetadata` component's object half back to a `BindingType`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `ALL_BINDING_TYPES`, `AT4DX_BINDING_OBJECTS`, `AT4DX_BINDING_LOCAL_OBJECT_NAMES`, `BINDING_TYPE_BY_FLAG`, `BINDING_RULES`                                                                                                  | Constants mapping `BindingType` to its Custom Metadata Type API name, local object name, and CLI flag spelling, plus `validateBindings`'s rule table.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `ALL_WRITABLE_BINDING_TYPES`, `WRITABLE_BINDING_TYPE_BY_FLAG`                                                                                                                                                              | Same, restricted to the three types `createBinding`/`updateBinding` support (no `UnitOfWork`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `BindingWriteError`                                                                                                                                                                                                        | The error `createBinding`/`updateBinding` throw, with a `code` (see `BindingWriteErrorCode`) instead of a message you'd have to string-match.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `AepConnection`                                                                                                                                                                                                            | The minimal connection shape `scanOrgBindings` needs (`autoFetchQuery`, `getUsername`) — accept this instead of a full `@salesforce/core` `Connection` if you're constructing one yourself.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `At4dxBindingRow`, `RawBindingRecord`, `At4dxBindingListResult`, `BindingType`, `BindingTypeFlag`, `BindingKeyField`, `RawApexTriggerRecord`                                                                               | Types for the row shapes above.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `WritableBindingType`, `WritableBindingTypeFlag`, `BindingIssue`, `BindingIssueRule`, `BindingIssueSeverity`, `At4dxBindingValidateResult`, `MalformedBindingRecord`, `AmbiguousBindingRecord`                             | Types for `validateBindings`'s input/output.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `BindingFieldsInput`, `CreateBindingInput`, `UpdateBindingInput`, `CreateBindingTarget`, `UpdateBindingTarget`, `At4dxBindingWriteResult`, `At4dxBindingCreateResult`, `At4dxBindingUpdateResult`, `BindingWriteErrorCode` | Types for the create/update functions above.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `BindingIssueScope`, `BindingRuleInfo`, `BindingXmlFields`, `LocalScanResult`, `OrgScanResult`                                                                                                                             | Supporting types: an issue's scope (`record`/`scan`) and per-rule metadata, `buildBindingXml`'s field subset, and the two scan-result envelopes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |

```ts
import {
  scanOrgBindings,
  scanOrgApexTriggers,
  resolveBindings,
  validateBindings,
  createBinding,
  ALL_BINDING_TYPES,
} from '@simplysf/simply-aep-core';

const { records, malformed, ambiguous, missingTypes } = await scanOrgBindings(connection, ALL_BINDING_TYPES);
const rows = resolveBindings(records);
// rows[n].effective tells you which record AT4DX actually resolves to for that binding key

const triggers = await scanOrgApexTriggers(connection);
const issues = validateBindings(records, { malformed, ambiguous }, triggers);
// issues.some(issue => issue.severity === 'error') tells you whether this project's Application Factory
// wiring is broken — including a Domain binding whose SObject has no trigger calling
// fflib_SObjectDomain.triggerHandler() for it (omit `triggers` to skip just that one check)

await createBinding(
  {
    bindingType: 'Selector',
    developerName: 'Account_Selector',
    sobject: 'Account',
    to: 'AccountsSelector',
    priority: 1,
  },
  { sourceDir: 'force-app/main/default' },
);
// writes force-app/main/default/customMetadata/ApplicationFactory_SelectorBinding.Account_Selector.md-meta.xml
```


### AT4DX Selector field set inclusions

`SelectorConfig_FieldSetInclusion__mdt` — tells a selector to add a named field set's items to its queried field list. Unlike the bindings above, there's no priority/winner concept: every `IsActive__c: true` record for a SObject contributes its field set simultaneously. See [design doc 0016](https://github.com/SimplySF/simply-plugins-core/blob/main/docs/design/0016-at4dx-selector-config-field-set-inclusion.md).

### AT4DX Platform Event subscriptions

`PlatformEvents_Subscription__mdt` — routes a platform event to a consumer class via AT4DX's `PlatformEventDistributor`, matched on the event's bus and its `Category__c`/`EventName__c` values per the record's `MatcherRule__c`. There's no priority/sequence: every active, matching subscription on a bus receives the event. See [design doc 0025](https://github.com/SimplySF/simply-plugins-core/blob/main/docs/design/0025-at4dx-platform-event-subscription-support.md).

| Export                                                                                                                                                                                                                                                                                                                                                                                                                             | Description                                                                                                                                                                                                                                                                                                                                                                                           |

| `scanOrgPlatformEventSubscriptions(connection)`                                                                                                                                                                                                                                                                                                                                                                                    | Queries a live org for `PlatformEvents_Subscription__mdt` records, and whether the Custom Metadata Type exists there at all.                                                                                                                                                                                                                                                                          |
| `scanLocalPlatformEventSubscriptions(sourceDirs)`                                                                                                                                                                                                                                                                                                                                                                                  | Scans local DX source for the same data.                                                                                                                                                                                                                                                                                                                                                              |
| `validatePlatformEventSubscriptions(scan, eventBusFields?)`                                                                                                                                                                                                                                                                                                                                                                        | Pure function: checks a scan for a blank/unrecognized bus, consumer, or matcher rule; a matcher rule that dereferences a blank match field (a runtime `NullPointerException` hazard); a subscription the distributor's pre-filter can never admit; an event bus missing the fields the distributor reads (when `eventBusFields` is given); a duplicate `Consumer__c`; and duplicate `DeveloperName`s. |
| `resolvePlatformEventDistribution(input, records)`                                                                                                                                                                                                                                                                                                                                                                                 | Pure function: simulates one event (`{ eventBus, category?, eventName? }`) through the distributor's control flow and returns every subscription that would receive it, plus every one on that bus that wouldn't and the structured reason (`inactive`, `prefiltered`, `matcher-rule-missing-field`, `no-match`).                                                                                     |

| `ALL_MATCHER_RULES`, `PLATFORM_EVENT_SUBSCRIPTION_OBJECT`, `PLATFORM_EVENT_SUBSCRIPTION_LOCAL_OBJECT_NAME`, `PLATFORM_EVENT_SUBSCRIPTION_RULES`                                                                                                                                                                                                                                                                                    | Constants for the recognized `MatcherRule__c` values, the Custom Metadata Type's API name, its local object name, and `validatePlatformEventSubscriptions`'s rule table.                                                                                                                                                                                                                              |

| `PlatformEventSubscriptionIssue`, `PlatformEventSubscriptionIssueRule`, `PlatformEventSubscriptionIssueSeverity`, `PlatformEventSubscriptionIssueScope`, `PlatformEventSubscriptionRuleInfo`, `At4dxPlatformEventSubscriptionValidateResult`, `EventBusFields`                                                                                                                                                                     | Types for `validatePlatformEventSubscriptions`'s input/output.                                                                                                                                                                                                                                                                                                                                        |
| `PlatformEventDistributionInput`, `PlatformEventDistributionMatch`, `PlatformEventDistributionMiss`, `PlatformEventDistributionMissReason`, `PlatformEventDistributionResult`                                                                                                                                                                                                                                                      | Types for `resolvePlatformEventDistribution`'s input/output.                                                                                                                                                                                                                                                                                                                                          |

```ts
import {
  scanLocalPlatformEventSubscriptions,
  validatePlatformEventSubscriptions,
  resolvePlatformEventDistribution,
  createPlatformEventSubscription,
} from '@simplysf/simply-aep-core';

const scan = scanLocalPlatformEventSubscriptions(['force-app/main/default']);

const issues = validatePlatformEventSubscriptions(scan);
// issues.some(issue => issue.severity === 'error') tells you whether this project's event routing is broken

const { matches, misses } = resolvePlatformEventDistribution(
  { eventBus: 'Order_Event__e', category: 'Fulfillment', eventName: 'OrderShipped' },
  scan.records,
);
// matches lists the consumers PlatformEventDistributor would invoke for that event; misses says why the rest wouldn't run

await createPlatformEventSubscription(

    developerName: 'Order_Shipped_Notify',
    eventBus: 'Order_Event__e',
    consumer: 'OrderShippedNotifier',
    matcherRule: 'MatchEventBusAndCategoryAndEventName',
    eventCategory: 'Fulfillment',
    event: 'OrderShipped',
  },
  { sourceDir: 'force-app/main/default' },
);
// writes force-app/main/default/customMetadata/PlatformEvents_Subscription.Order_Shipped_Notify.md-meta.xml
```

### Code generation

Scaffolds fflib and AT4DX layers — selector, domain (with its trigger), service, unit of work — and the AT4DX criteria/action classes, selector methods, and field set inclusions, each with its unit test and, for AT4DX, its Custom Metadata binding. The engine behind `sf simply aep generate ...`, ported from [`@syntax-syllogism/apx-core`](https://github.com/Syntax-Syllogism/apx-core) (whose dead-code analysis stays there). Binding records are written by the `build*Xml` functions above, so a generated record and one `create*` writes can't differ. See [design doc 0045](https://github.com/SimplySF/simply-plugins-core/blob/main/docs/design/0045-aep-core-generation-engine.md).

Each generator is a use case with a `plan` (validate options, describe the SObject if needed, render every file — writes nothing) and an `apply` (write the plan).

| Export                                                                                                                                                                                 | Description                                                                                                                                                                                                                                                              |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `generate`, `generateSelector`, `generateDomain`, `generateService`, `generateUnitOfWork`, `generateSelectorMethod`, `generateFieldSetInclusion`, `generateAction`, `generateCriteria` | The use cases. `plan(connection, options, { projectRoot })` returns a `GenerationPreview`; `apply(connection, preview, { overwrite })` writes it, refusing (`file-exists`, every existing path in `data.absolutePaths`) unless `overwrite` is `'overwrite'` or `'skip'`. |
| `generationUseCases`, `generationCommandDescriptors`                                                                                                                                   | The same, keyed by id, and their descriptors (`id`, `cliId`, `title`, `requiresOrg`, `optionsSchema`).                                                                                                                                                                   |
| `planValidation(preview, sourceDirs)`                                                                                                                                                  | The validation issues a preview's CMDT records would introduce into `sourceDirs` — pre-existing problems aren't included. Each `GenerationIssue` is tagged `record: 'binding' \| 'domain-process-binding' \| 'field-set-inclusion'`.                                     |
| `generate*OptionsSchema`, `uiHints(schema)`                                                                                                                                            | The zod option schemas, and the prompt hints (`label`, `kind`) a form or interactive CLI renders from.                                                                                                                                                                   |
| `renderGenerationPlan(preview)`, `renderGenerationResult(outcome, { commandId })`, `describeGenerationError(error)`                                                                    | Human-readable lines for a preview, a result, and an error (including a zod validation error).                                                                                                                                                                           |
| `AepGenerationError`, `isAepGenerationError`                                                                                                                                           | What the engine throws on purpose, with a stable `code` (`org-required`, `nothing-selected`, `file-exists`, `sobject-not-found`, ...).                                                                                                                                   |
| `build*Names`, `PathResolver`, `DEFAULT_LAYOUT`, `build*Plan`, `combinePlans`, `GenerationEngine`, `planGeneration`, `applyGeneration`, `describeTarget`, `toDescribeView`, `resolve*` | The lower layers the use cases are built from: naming rules, the output layout, per-artifact plan builders, the write engine, and describe/API-version/output-path resolution.                                                                                           |

```ts
import { generateDomain, planValidation } from '@simplysf/simply-aep-core';

const preview = await generateDomain.plan(connection, { sobject: 'Account', flavor: 'at4dx' }, { projectRoot });
const issues = planValidation(preview, ['force-app', preview.baseDir]);
if (!issues.some((issue) => issue.severity === 'error')) {
  await generateDomain.apply(connection, preview);
  // writes generated-files/main/classes/domains/Accounts.cls, its interface, test, trigger, and binding
}
```
